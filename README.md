# 旅する英会話

仕様書「英会話上達Webアプリ 仕様書 v0.1」をもとにした、iPhone 向けの英会話Webアプリ。
AI（Gemini Live API）と英語で音声会話し、Lv1「売店で買い物」から Lv10「一人旅」までを段階的に練習する。
サーバーは持たず、利用者が自分の Gemini APIキーを入れて、その人の利用枠で動く。

## できること（仕様書との対応）

| 仕様 | 実装 |
| --- | --- |
| 10段階のレベル・3段階のサポート（4章） | `js/data.js` に Lv1〜10 の場面30個＋昇格テスト。手厚い/補助/自立で画面とAIの振る舞いを切り替え |
| 準備→会話→振り返り（5.1） | 準備画面（口慣らし）→ 会話画面 → 振り返り画面 |
| 音声→音声・押して話す・割り込み・再接続（5.2, 9.1） | `js/live.js`（WebSocket直結、自動再接続）、`js/audio.js`（16kHz変換、エコーキャンセル） |
| 初心者フォロー（5.3） | 返答候補3つ（タップで読み上げ）、日本語訳、Slower please、沈黙5秒でヒント強調、日本語で質問OK |
| 上級の自由会話（5.4） | Lv8〜10は台本なし、AIだけが知る「隠し条件」で毎回展開が変わる |
| 100点評価（6.1） | 目的・伝わりやすさ・文法はFlash-Liteで判定、流暢さ・自立度は端末で計測 |
| レベルアップ（6.2） | 直近5回平均75点＋目的達成4回で昇格テスト解放、80点で合格、不合格は24時間後に再受験 |
| 復習（6.3） | 言い直し例を復習カードに（1・3・7・14日の間隔反復、会話内でも再出題）、2週間ごとの定着チェック、要復習マーク |
| 7画面（7章） | ホーム／レベルマップ／場面選択／会話／振り返り／復習／成長記録＋設定 |
| 無料枠・有料枠（8.1） | 自己申告のモード切替、有料枠案内（拡張機能選択時・制限超過が続いたとき・Lv8到達時、7日間は再表示しない）、月の上限分数と使用量メーター |
| データ保存（8章） | IndexedDB（端末内のみ）。ファイルへの書き出し・読み込み |

## ファイル構成

```
index.html            入口（PWA対応・ホーム画面に追加可）
css/app.css           見た目
js/app.js             画面とルーター
js/talk.js            会話画面と採点
js/live.js            Gemini Live API クライアント
js/audio.js           マイク入力・音声再生・読み上げ
js/capture-worklet.js マイク音声を16kHz PCMに変換
js/gemini.js          REST API（モデル一覧・採点・返答候補）
js/prompts.js         AIへの指示文
js/progress.js        評価・レベルアップ・復習・利用量
js/store.js           端末内保存
js/data.js            レベルと場面のデータ
sw.js                 オフライン用キャッシュ
```

ビルド不要。ファイルをそのまま HTTPS のホスティングに置けば動く。

## 動かし方

### パソコンで確認する

`アプリ制作` フォルダで次を実行する。

```bash
python -m http.server 8765 --directory 英会話
```

ブラウザで http://localhost:8765 を開く（localhost ではマイクが使える）。

### iPhone で使う

iPhone の Safari では **HTTPS でないとマイクが使えない**ため、GitHub Pages などの無料ホスティングに置く。
公開後、Safari でURLを開き「共有」→「ホーム画面に追加」でアプリのように使える。
公開前に `app-release-check` スキルで点検すること。

## 使うモデル

- 会話：APIキー確認時にモデル一覧を取得し、Live API 対応の最新モデル（例：`gemini-3.8-live`）を自動選択。設定で変更可
- 採点・返答候補：Flash-Lite 系の最新モデルを自動選択
- 有料枠モードの「詳しい採点」：Flash 系の最新モデル

## 試作で決めること（仕様書 9.3）

- 無料枠で上限に達しにくい1日の回数の目安：仮に10回（`js/app.js` の `FREE_DAILY_GUIDE`）
- 昇格基準 75点・80点：`js/progress.js` の `UNLOCK_AVG` / `PASS_SCORE`
- 1回あたりのAPI使用量：実機で計測して調整する
